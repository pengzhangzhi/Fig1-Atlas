Design your Figure 1 with a coding agent

Open Claude Code or Codex in the folder that holds your draft and paste this. Notes or a one-paragraph idea work too.

What the agent does

  1. Reads your draft and writes down the one claim Figure 1 has to make, and which of the eight roles that is.
  2. Searches the atlas by role and tags, reads the shortlisted entries and looks at the figures themselves.
  3. Shows you three to five templates from accepted papers, each with a link, the reason it fits, and what would go in each panel for your paper. It recommends one.
  4. Drafts the figure once you pick, in the format you work in: TikZ, matplotlib, SVG or slides.

The search is plain Python over a text index. It needs no API key and no extra packages.

Install it as a skill

If you write papers often, keep the atlas as a Claude Code skill. After this, “design my Figure 1” is enough.

git clone https://github.com/pengzhangzhi/Fig1-Atlas ~/.claude/skills/fig1-atlas

Agents without a shell

A chat assistant that can browse but cannot run code can start from llms.txt. It explains how to filter index.json and open one entry as p/<id>.json.

Search it yourself

python3 scripts/search.py --role prior-vs-ours --tags one-step,distillation --limit 30
python3 scripts/search.py --role pipeline,concept --q "teacher student"
python3 scripts/show.py iclr26-0566 iclr26-0516
python3 scripts/fetch_fig.py iclr26-0566

The first two list matching figures as id, venue, role, title and claim. show.py prints the full entry. fetch_fig.py downloads the image.
