Install as a Claude Code skill

git clone https://github.com/pengzhangzhi/Fig1-Atlas ~/.claude/skills/fig1-atlas

Then ask “design my Figure 1”. The skill reads your draft, picks one or two roles, searches the index with scripts/search.py, reads shortlisted entries with show.py, looks at images with fetch_fig.py, and returns 3–5 templates with a panel-by-panel mapping and one recommended pick.

Browsing agents

Agents without a shell can read /llms.txt, filter /index.json directly, and open one paper as /p/<id>.json.

Search examples

python scripts/search.py --role prior-vs-ours --tags one-step,distillation --limit 30
python scripts/search.py --role pipeline,concept --q "teacher student"
python scripts/show.py iclr26-0566 iclr26-0516
python scripts/fetch_fig.py iclr26-0566
